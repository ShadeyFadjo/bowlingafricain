# AFRICAN_BOWLING
## Technology
- Python
- Flask
## Installation
- Make sure you have Python installed
- Clone this repository on your computer
- At the project root in your computer, open your terminal and run the command: pip install flask
- Then, still in the terminal, to run the flask server, run the command: flask --app accueil run 
- Enter the URL http://localhost:5000/ in your browser, and the application will start
## Documentation
### User's guide
- You just need to enter the number of pins knocked down for each round in the section: 'Nombre de quilles touchées' and submit.
- All other informations and data are calculated automatically
- When there is a spare or a strike, an input field for entering the total number of pins knocked down during the 2 or 3 bonus rounds will appear.
Enter the total number of pins knocked down in this new input field, and then submit
- All other processes are automated
- Press the button 'Init game' to re-init the game
